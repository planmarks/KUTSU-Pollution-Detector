Prototype purpose:
1. Device that monitors the environment and displays real time results on the OLED display.
2. The device gives extra notifications on display and via buzzer when any sensors readings are abnormal.

Device use workflow:
1. The device is turned on via on-off switch.
2. While the firmware is loading, a welcome screen is displayed with the device name and logo. When firmware is loaded, the device starts displaying real time sensor readings that are updated with 1 second intervals.
3. Using a push button, the user can switch between 2 screens. First (main screen) with real time results and second screen that displays column charts of readings spanning 1h. One press switches to chart screen, another one press switches back to the real time reading screen.
4. If any measurement is registered as abnormal (by abnormal we mean a measurement that is considered harmful when a human is exposed to it), the display shows a full screen notification of the abnormal measurement and that it's harmful. When an abnormal measurement is registered and notification is displayed, the buzzer makes noise as well.
5. If a MicroSD card is inserted into the devices MicroSD Breakout Board, the logs are automatically saved onto the SD card. If no SD card is inserted, the logs are saved into the flash memory for as long as the device is turned on. If the device flash memory is full, logs are deleted chronologically.
6. NFC I2C NTAG Module should store a text file that has users health details and emergency contacts written onto it. If someone with an NFC reader scans it, they should obtain Users full name, date of birth, blood type.
