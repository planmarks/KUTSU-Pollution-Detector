Kutsu Flasher

Install or update Kutsu Sense firmware over USB — right from your browser.

  1. Use desktop Chrome or Edge.
  2. Plug the Kutsu into USB-C (the board's native USB port).
  3. Click Install / Update, pick the serial port, and wait — the board is detected automatically and the matching build is flashed.
This browser can’t flash over USB. Open this page in desktop Chrome or Edge.

Flashing rewrites the whole chip. Your Wi-Fi credentials, room label, device name and settings live in a separate NVS area and are normally preserved across an update; a full erase (offered by the installer) clears them.

Which build?

One firmware serves every Kutsu module — XIAO ESP32-C3 / C5 / C6 / S3. The flasher reads the connected chip and installs the right one from the manifest, so you don’t choose.

Note: ESP32-C5 support depends on the esptool-js version behind ESP Web Tools. If a C5 board isn’t recognised, flash it over USB from the Arduino IDE for now, or pin a newer esptool-js — see the README.
